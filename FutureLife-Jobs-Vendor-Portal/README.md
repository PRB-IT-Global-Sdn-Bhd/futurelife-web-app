# FutureLife Jobs Vendor Portal

## Open the portal

Open `jobs-vendor-portal.html` in a modern web browser.

## Included areas

This single-page portal preview includes dashboard, job listings, create and edit job flow, applicants, hires and placements, messaging, billing plans, job-posting fees, placement fees, notifications, profile, and settings views.

## Preview-only notice

This is a static visual prototype. It does not include production authentication, database storage, Stripe processing, real messaging, or actual hiring and billing workflows. Dynamic values such as `{{JOB_ID}}` are placeholders for Bubble or backend data.
