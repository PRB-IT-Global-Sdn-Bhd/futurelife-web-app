# FutureLife Rentals Vendor Portal

## Open the portal

Open `rentals-vendor-portal.html` in a modern web browser.

## Included areas

This single-page portal preview includes dashboard, properties, applications, tenancies, move-in workflows, messages, billing plans, listing fees, rental commissions, notifications, profile, and related management views.

## Preview-only notice

This is a static visual prototype. It does not include production authentication, database storage, payments, real messaging, or actual rental operations. Dynamic values such as `{{PROPERTY_ID}}` and `{{TENANCY_REFERENCE}}` are placeholders for Bubble or backend data.
